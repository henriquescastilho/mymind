Método de trabalho

1. Descoberta objetiva

Preencha perguntas essenciais para definir escopo, público, arquitetura e restrições de privacidade sem incluir dados reais.

2. Geração orientada

Use o prompt-base para pedir ao Codex ou ao Claude Code uma primeira versão editável e consistente do projeto.

3. Revisão e publicação

Rode verificações com `rg`, ajuste os arquivos e publique só o que é seguro, útil e revisável.

Gerador rápido de prompt

Informe o mínimo necessário e gere um prompt de partida. Depois, refine com o arquivo completo `KIT_PERGUNTAS_E_PROMPT.md`.
